Core Experience
How a support call works
📞
Caller Dials In
Harold answers. Collects name, phone, email, order number.
🔍
Issue Triage
Harold asks targeted questions to understand the technical problem.
🔗
Secure Link Sent
Caller gets an SMS upload link. They open it on their phone.
📸
Photo / Video
Caller uploads a photo or short video of the vehicle issue.
🤖
AI Analysis
GPT-4o Vision analyzes the image and returns a full diagnosis.
📋
Harold Reads Back
Harold reads the findings and recommended steps to the caller.
📁
Case Created
If escalation is needed, a case is logged with all evidence attached.
AI Decision Engine
6 Resolution Routes

After the visual analysis, the AI returns a recommended_route that tells Harold exactly how to handle the call. No human judgment required on routing.

🔧
Self Fix
Issue is owner-serviceable. Harold walks the caller through safe, step-by-step repair instructions live on the call.
📦
Replacement Part
A specific part needs replacing. Case created, parts team is notified with the AI's part identification.
🛡️
Warranty Replacement
Defect is within warranty coverage. Warranty team is notified automatically with the full analysis and media.
🕒
Out of Warranty
Warranty has expired. Service team is notified to provide the best available repair or upgrade options.
🚨
Safety Stop
Potential safety issue detected. Harold instructs caller not to use the vehicle. Immediate escalation to a specialist.
👤
Human Support
Issue is too complex to resolve on the call. Full case created with all context for the specialist team.

Roadmap
Planned Additions
01
🎙️
Call Recordings
Embed Retell call recordings directly in the case detail view. Agents can play back the full conversation alongside the transcript and visual evidence — no need to leave the dashboard.
  • Receive recording_url from Retell webhook on call end
  • Store URL on the case record in KV
  • Render inline audio player in the case detail page
  • Show call duration and timestamp
02
📝
Full Transcripts
Store and display the complete call transcript on each case. Searchable by keyword, with speaker labels so agents can scan quickly for key moments without listening to the full recording.
  • Receive transcript array from Retell webhook
  • Store on case with speaker labels (agent / user)
  • Render with timestamp markers and scroll anchors
  • Add keyword search / highlight within transcript
03
📊
Call Metadata & Variables
Capture all Retell call variables on every case — sentiment, detected language, call duration, agent version, dynamic variables set during the call — for analytics and quality review.
  • Capture all call_analysis fields from Retell webhook
  • Store sentiment, language, DTMF, latency stats
  • Display structured metadata panel on case detail
  • Surface trends on a future analytics dashboard
04
🔔
Case Assignment & Notes
Let support agents assign open cases to themselves, add internal notes, and update case status — turning the dashboard from a read-only log into a working ticket system.
  • Add assigned_to, notes[] to the ServiceCase schema
  • Build inline assignment UI with agent list
  • Internal notes panel with timestamp and author
  • Status transitions: open → assigned → resolved
Architecture
Technical Stack
🤖
Retell AI
Voice agent platform. Harold runs as a custom LLM agent with three server-side tools.
⚡
Next.js 14
App Router. All Retell tools are serverless API routes. Dashboard runs server-side.
🗄️
Vercel KV
Redis-backed store for sessions and cases. Custom client prevents Next.js fetch caching.
🗂️
Vercel Blob
Private blob store for caller photo and video uploads. Served via server-side proxy.
👁️
GPT-4o Vision
Analyzes uploaded media and returns structured diagnosis with confidence and routing.
📱
SMS Upload
Secure per-session upload URL texted to caller. Accepts photo and video up to 25MB.
🌐
Vercel Edge
Global edge deployment. Sub-100ms cold start on all API routes for real-time call use.
🔒
Private by Default
All media in private blob storage. Accessed only via authenticated server-side proxy route.
